# `setMaxWorkers()`

Set the process-wide maximum number of active `run` workers.

```ts
import { setMaxWorkers } from 'run';

setMaxWorkers(8);

// Restore the dynamic memory-based default.
setMaxWorkers();
```

## Import

```ts
import { setMaxWorkers } from 'run';
```

## API Signature

### Parameters

```json
[
  {
    "name": "maxWorkers",
    "type": "number",
    "isOptional": true,
    "description": "A positive integer worker cap. Omit the value or pass undefined to restore the dynamic memory-based default."
  }
]
```
