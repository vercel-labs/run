# Errors

Errors exported by `run`.

```ts
import { RunError, run } from 'run';

try {
  await run({ source });
} catch (error) {
  if (RunError.isInstance(error)) {
    console.error(error.code, error.details);
  }
}
```

## Import

```ts
import {
  RunAbortedError,
  RunHostFunctionError,
  RunBridgeLimitError,
```
