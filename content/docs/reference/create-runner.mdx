# `createRunner()`

Create a reusable runner with shared resource limits and continuation
configuration.

```ts
import { createRunner } from 'run';

const runner = createRunner({
  limits: { timeoutMs: 10_000 },
  syncHostFunctions: {
    values: {
      read: () => 42,
    },
  },
});

const result = await runner.run<number>({
  source: 'return 6 * 7;',
});
```
